# Publish your GitHub profile

1. On GitHub, create a **public** repository named exactly `anand-kumar7890` (same as your username).
2. Make sure the repository is initialized with a README, or upload these files directly.
3. Upload `README.md`, the `assets/` folder, and `.github/workflows/snake.yml` while preserving their paths.
4. Commit to the `main` branch. Your profile README will appear at https://github.com/anand-kumar7890.
5. Open the repository's **Actions** tab and run **Generate contribution snake** once. The workflow publishes the animation to the `output` branch.
6. After the first successful run, add this below the GitHub stats section in `README.md` if you want the contribution animation visible:

```md
<p align="center">
  <img src="https://raw.githubusercontent.com/anand-kumar7890/anand-kumar7890/output/github-contribution-grid-snake-dark.svg" alt="Contribution graph animation" />
</p>
```
