## Publish
1. Extract this ZIP.
2. Open your cloned profile repository folder (the one containing `.git`).
3. Replace its `README.md` and copy the complete `assets` folder.
4. Run:

```powershell
git status
git add README.md assets
git commit -m "Redesign profile with Notion-inspired portfolio"
git push origin main
```

Keep `README.md` and `assets/` at the repository root. Do not create an extra nested `anand-notion-profile` folder inside the repository.
